# 利回り資産、またはそれを担保にした借り入れを探す

NODO は、利回りを生む資産と、その資産を担保にした借り入れの、一つの現在の一覧を持つ。ネオバンク、保有者、別のプロジェクトのどれもが読める。一覧を読む。借りない。買わない。借り入れを準備しない。

`nodo` を使う。つながっていなければ止まり、その旨を言う。行を作らない。

## プロダクト

1. `list_assets` を呼ぶ。`limit` を省くと 10 行である。`nextOffset` を次の `offset` に渡し、空になるか、答えが足りるまで続ける。
2. その一覧の `assetId` で `get_asset` を呼ぶ。名称やティッカーから id を組み立てない。
3. 名称、ティッカー、発行者、利回り、規模、条件を伝える。`asOfTime` があるときは含め、数字を取った時刻が分かるようにする。

`get_asset` に購入や償還の経路は含まれない。補わない。

## オポチュニティ

オポチュニティは、一つの利回り資産を一つの貸出市場で担保に置いたものである。使う数字は、利息を引いたあとに残る利回りと、担保が売却される点より手前に収まる最大の借り入れである。

1. `list_opportunities` を呼ぶ。ティッカーや名称には `search` を使う。相手が名指ししたときは `yieldToken`、`protocolIds`、`debtToken`、`minNetApy` を使う。
2. `opportunityId` をそのままコピーして `get_opportunity` を呼ぶ。
3. 会場（`protocolId`）、担保、債務、基礎利回り、ネット年率、レバレッジ、最大 LTV、アクセスを伝える。`projectionStatus` が `available` でないときは、その状態を引用する。

`get_opportunity` に取得経路は含まれない。calldata も、建玉を開く要求も、下書きしない。

## 止める

規模を見積もる、開く、承認する、確定する、といった借り入れを頼まれたら、このプログラムにはできないと伝える。借り入れの準備は NODO の API で行う。このリポジトリの別の道具で迂回しない。
